# 고블린 디펜스 (DTC)

여러 방향에서 쳐들어오는 고블린을 막아 성을 지키는 도트 디펜스 게임.

**플레이:** https://kiwoong1108.github.io/DTC/

## 흐름
스테이지 지도 → 전투 → 마인드맵 강화 → 전투 …

## 조작
- 지도: 노드 클릭으로 이동, 출격 / 방향키 + Enter
- 전투: 소환 버튼 또는 Space로 기사 소환, 땅 클릭으로 기사 이동, 성 클릭으로 자동 전투, Esc 일시정지
- 강화: 드래그로 이동, 휠로 줌, 노드 클릭으로 강화

## 버전
- v0.0.1 — 첫 배포. 스테이지 1-1~1-6, 기사·고블린·고블린 왕, 성 Lv.1~10, 강화 트리 20개 노드
