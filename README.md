# Defend The Crown — 왕관을 지켜라

여러 방향에서 쳐들어오는 고블린을 막아 성과 왕관을 지키는 도트 디펜스 게임. (구 이름: 고블린 디펜스)

**플레이:** https://kiwoong1108.github.io/DTC/

## 흐름
시작 화면 → 스테이지 지도 → 전투 → 마인드맵 강화 → 전투 …

## 조작
- 지도: 자물쇠·번호판 클릭 또는 방향키로 이동, 하단 출격 버튼 → 브리핑 창에서 출격
- 전투: 소환 버튼 또는 Space로 기사 소환, 땅 클릭으로 기사 이동, 성 클릭으로 자동 전투, 좌상단 속도 버튼(×1 / ×1.5 / ×2 / ×1/2), Esc 일시정지
- 강화: 드래그로 이동, 휠로 줌, 노드 클릭으로 강화
